About 3D Maze

3D Maze

Windows 95 Screen Saver — web remake

A little brick corridor that wanders off on its own, with the odd rat lurking in a dead end. It is a raycast maze, a handful of ClassicCraft block textures, and absolutely no reason to exist.

  • Double-click 3D Maze to start.
  • Exit with the on-screen Exit button, a click, or Esc. It stays in the browser — no fullscreen.
  • Settings and Shut Down are in the Start menu.

Block textures from ClassicCraft by Heath Logan Campbell (MIT licence).
